STUDY TRACKER
Overview

Study Tracker is a simple Python project designed to help students organize and monitor their study tasks. It allows users to enter tasks, track their completion, view pending and completed tasks, and calculate their overall progress.

FEATURES
Add multiple study tasks
Track completed and pending tasks
Calculate study progress percentage
Interactive user input
Simple and beginner-friendly interface
Technologies Used
Python
Python IDLE
Functions
Lists
Loops
Conditional statements
HOW TO RUN
Install Python 3.x.
Download or clone this repository.
Open the project folder in Python IDLE.
Run the main Python file.
Follow the instructions shown in the terminal.
TESTING

The project is tested using different numbers of tasks and different completion statuses to check whether completed tasks, pending tasks, and progress percentage are displayed correctly.

PROJECT STRUCTURES

The project is divided into separate Python files/modules to keep the code organized and easy to understand.
